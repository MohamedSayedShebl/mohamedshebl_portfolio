# Project screenshots

The portfolio (`../index.html`) loads project screenshots from these folders:

| Folder | Project card |
|---|---|
| `tourmate/` | Tourmate-AI (graduation project) |
| `freshmart/` | FreshMart |
| `univa/` | Univa — Course Management System |

## Adding screenshots

1. Drop your image files into the matching folder.
2. Make sure the file names are listed in the `projectScreenshots` object at the
   bottom of `../script.js` (defaults are `1.png`, `2.png`, `3.png`, ...).
3. Missing files are skipped automatically — the card shows its placeholder icon
   until at least one image exists.

Recommended: portrait phone screenshots around 1080×1920 work best.
